Comparing **forward P/E** across peers adds a layer that trailing comparisons do not have: you are comparing **forecasts**, and forecasts for different companies may come from different analysts, different dates and different assumptions. A company can look cheap on forward P/E simply because its estimate is the most optimistic in the group.

This post covers the forward-specific steps. Build the peer group and align basics (business model, currency, EPS type) first using [P/E vs peers: a Canada-first comparison guide](/investing/valuation/pe-vs-peers-canada-first-comparison/). It is educational; figures are hypothetical.

## Direct answer

Use the **same forward period for every company**, ideally **next twelve months (NTM)**, so October and December year ends line up. Pull all estimates from **one source on one date**. Show **trailing and forward P/E side by side** and calculate each company's **implied growth**. If your company's forward discount comes mainly from a higher growth estimate, test that estimate before calling the stock cheap. Note coverage (number of analysts) and recent **revisions** for each name.

## Alignment rules for forward comparisons

| Rule | Why |
|:--|:--|
| NTM for everyone | Removes fiscal year differences (for example, banks at October 31) |
| One data source, one date | Consensus differs by provider and changes daily |
| Same EPS basis | Most consensus is adjusted; check that every peer uses the same adjustments |
| Same currency | Convert USD estimates for TSX names that report in USD |
| Coverage noted | A peer with one estimate is weaker evidence |
| Revision trend noted | Rising vs falling estimates change the picture |

## Peer table template (forward view)

| Company | Trailing P/E | Forward P/E (NTM) | Implied growth | Analysts | 3-month revision | Notes |
|:--|--:|--:|--:|--:|:--|:--|
| Your company | | | | | Up / flat / down | |
| Peer A | | | | | | |
| Peer B | | | | | | |
| **Median** | | | | | | |

Implied growth = trailing P/E ÷ forward P/E − 1. In the chart above, 14.0 ÷ 11.0 − 1 ≈ 27%.

## How to read the result

| Pattern | Likely meaning | Next step |
|:--|:--|:--|
| Discount on both trailing and forward | Market sees more risk or lower quality | Look for the risk; check balance sheet and ROE |
| Discount only on forward | Estimate assumes above-peer growth | Test the growth with [your own forward EPS](/investing/valuation/calculate-forward-pe-in-cad-from-filings/) |
| Premium only on forward | Estimate assumes below-peer growth or a dip | Check if the dip is temporary |
| Similar on both | Market and estimates agree | Valuation is not the main question |

For a peer group with very different growth rates, a growth-adjusted view (such as PEG) can help, but it adds another estimate. Use it as a cross-check, not the main answer.

## Checklist

| Step | Done when |
|:--|:--|
| Basics aligned | Peer set and EPS basis set using the trailing P/E guide |
| NTM used | Every company on next-twelve-month estimates |
| Source and date fixed | All estimates from one provider, same day |
| Implied growth calculated | For every company in the table |
| Coverage and revisions noted | Analysts and 3-month revision trend recorded |
| Gap explained | Forward discount or premium tied to a reason |

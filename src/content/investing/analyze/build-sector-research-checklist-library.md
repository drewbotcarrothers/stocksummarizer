After a few years of research, most DIY investors end up with a pile of notes, half-finished templates and bookmarks. A **checklist library** fixes that. It is a small, organized set of checklists: one core checklist you use for every stock, plus one **sector overlay** for each industry where the default tools break.

This post is a **hub**. It does not add new checklists. It shows how to organize the sector checklists already on this site so you can pick the right one in seconds. It is educational and is not a recommendation of any stock or sector.

## Direct answer

Build the library in three layers: (1) a **core checklist** (business model, filings, balance sheet, valuation, risks) that never changes; (2) a **sector overlay** for each industry that lists which default metrics to switch off and which to use instead; and (3) **company notes** (thesis, kill criteria, quarterly scorecard). Store them in one place, name them consistently, and review the overlays once a year.

## How to organize the library

| Rule | Why |
|:--|:--|
| One file per checklist, same headings in each | Easy to compare and update |
| Name files by sector, not by company | Overlays are reused across companies |
| Link each company note to its sector overlay | You always know which metrics apply |
| Date every change | You can see how your process evolved |
| Review overlays once a year | Accounting rules and regulation change |
| Keep a "not applicable" line | Shows you considered a metric and chose to skip it |

For note-keeping habits that support this, see [how to keep stock research notes that compound over years](/investing/analyze/keep-stock-research-notes-that-compound/) and [how to build a watchlist process that is not noise](/investing/analyze/build-watchlist-process-not-noise/).

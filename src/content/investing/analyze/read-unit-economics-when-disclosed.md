Some issuers disclose **unit economics**: revenue per subscriber, contribution per store, cost per delivery, CAC and payback, and similar. Used well, they explain whether growth is **value-accretive**. Used badly, they are vanity charts that ignore overhead, churn, and capitalization choices.

Educational only — not financial advice. Numbers are **hypothetical**. Link [operating leverage](/investing/analyze/analyze-operating-leverage/), [FCF checklist](/investing/analyze/fcf-stock-decisions-quick-checklist/), and [non-GAAP literacy](/investing/analyze/read-non-gaap-metrics-critically/).

## Direct answer

Only analyze unit economics the company **actually discloses**. Lock the unit definition and cohort rules. Build revenue/unit and variable cost/unit stacks, then contribution/unit. If CAC / payback appears, test retention and whether corporate overhead is excluded. Ask whether scaling improves or dilutes the unit. Never let a pretty unit chart override consolidated cash flow and balance-sheet risk.

## Common unit metrics and failure modes

| Metric | Useful when | Failure mode |
|:--|:--|:--|
| ARPU / average ticket | Price/mix clarity | Mix shift hidden; discounts excluded inconsistently |
| Contribution / unit | Variable margin visible | "Contribution" omits obvious variable costs |
| CAC & payback | Growth efficiency | Organic vs paid CAC muddled; payback ignores churn |
| Same-store contribution | Store maturity | New stores forever excluded |
| Take rate | Marketplace health | Gross vs net revenue confusion |

## Hypothetical decision note

| Item | Hyp. value | Note |
|:--|:--|:--|
| Unit | Monthly active subscriber | Issuer-defined |
| Revenue / unit | $42 | Net of discounts |
| Variable cost / unit | $18 | Hosting + support variable |
| Contribution / unit | $24 | Before corporate opex |
| CAC | $60 | Paid + sales (issuer view) |
| Implied payback | ~2.5 months if no churn | Unrealistic — apply retention |
| Lean | Watch | Need cohort retention table |

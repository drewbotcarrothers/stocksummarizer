[What is dilution?](/investing/glossary/what-is-dilution/) explains the concept. This spoke is about spotting **dilution risk before an issue** — shelf prospectuses, warrant overhang, convertibles, ATM programs, and a thin cash runway.

Educational only — not financial advice. Share counts are **hypothetical**. Monitor filings with [SEDAR+ alerts](/investing/analyze/sedar-plus-alerts-filing-types-monitoring/).

## Direct answer

Before you need a surprise financing headline, map cash runway, existing dilutive overhang (options, warrants, convertibles), any base shelf prospectus or ATM prospectus supplement on SEDAR+, and near-term triggers (maturities, covenants, committed capex). Write dilution risk into the thesis while it is still optional.

## Dilution-risk checklist

| Item | Where to look | Your notes |
|:--|:--|:--|
| Cash + short-term investments | Balance sheet | |
| Quarterly cash burn / FCF | Cash flow statement | |
| Runway (months, rough) | Your calc (hyp. method) | |
| Options / RSUs outstanding | Equity note | |
| Warrants | Equity / warrant note, AIF | |
| Convertible debentures | Debt note | |
| Base shelf prospectus | SEDAR+ | |
| ATM / equity distribution agreement | SEDAR+ prospectus supplements | |
| Near-term debt maturity | Debt note / MD&A | |

## Filing types that often precede issuance

| Filing / event | Why it matters |
|:--|:--|
| Base shelf prospectus | Creates capacity for future takedowns |
| Prospectus supplement / bought deal PR | Actual or imminent issuance |
| Material change report on financing | Formal continuous-disclosure trail |
| Warrant exercise / amendment PR | Overhang changing shape |

Early-warning and insider pieces are separate — see NI 62-104 / NI 62-103 and SEDI under NI 55-104; this post stays on issuer-side issuance risk.
